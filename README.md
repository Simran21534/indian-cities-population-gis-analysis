# Indian Cities Population & GIS Spatial Analysis

> A Python-based geospatial analysis project exploring population distribution and spatial relationships among major Indian cities using GeoPandas and GIS techniques.

## 📌 Project Overview

This project analyzes major Indian cities using population data and Geographic Information System (GIS) techniques.

The project combines demographic data with geographic information to explore population distribution, city locations, state boundaries, and spatial relationships between cities.

## 🎯 Objectives

- Analyze population distribution across Indian cities
- Perform geospatial data processing using Python
- Work with geographic coordinates and CRS
- Perform spatial joins between cities and states
- Calculate nearest-city distances
- Visualize population distribution geographically

## 📊 Analysis Performed

### 1. Population Analysis

Analyzed population estimates of major Indian cities and identified cities with higher population values.

### 2. Spatial Analysis

Used geographic coordinates to calculate distances between cities and identify nearest-city relationships.

### 3. Spatial Join

Connected city point data with geographic state boundaries using point-in-polygon spatial joins.

### 4. GIS Visualization

Created maps showing:

- Indian state boundaries
- Major city locations
- Population-based city markers
- Nearest-city relationships
